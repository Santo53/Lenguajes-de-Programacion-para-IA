## Cómo ejecutar los notebooks

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Santo53/Lenguajes-de-Programacion-para-IA.git
   cd Lenguajes-de-Programacion-para-IA
   ```
2. Instalar las dependencias principales:
   ```bash
   pip install numpy pandas matplotlib jupyter
   ```
3. Abrir Jupyter y navegar a la carpeta de la clase:
   ```bash
   jupyter notebook
   ```

También se pueden abrir directamente en **Google Colab** o **VS Code**.
